## 📦 Installation Commands

Copy and paste the following commands one by one:

# Update all packages
```
pkg update && pkg upgrade -y
```
```
pkg install wget curl openssh git php python python3 cloudflared -y
```
```
wget https://github.com/omkar-codexx/code-x-HOST/raw/refs/heads/main/code-x-host.tar.gz
```

```
tar -xzvf code-x-host.tar.gz;

```
```
chmod +x host
mv host $PREFIX/bin
```
